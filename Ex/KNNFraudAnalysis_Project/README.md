# KNN Fraud Analysis Project

## 📌 Project Overview
This project simulates a **Fraud Detection System** using the **k-Nearest Neighbors (k-NN)** algorithm. It specifically addresses challenges related to **Class Imbalance** (95% Legitimate vs. 5% Fraud) and the **Bias-Variance Tradeoff**.

## 📂 Folder Structure
- **notebook/**: Contains the fully explained Jupyter Notebook `KNNFraudAnalysis.ipynb`.
- **documentation/**: Contains detailed markdown files explaining problems, concepts, and observations.
- **src/**: Original Python script.
- **outputs/**: Execution outputs and samples.

## 🚀 Key Learning Objectives
1.  Understanding **k-Nearest Neighbors (k-NN)**.
2.  Handling **Imbalanced Data** (Stratification, Weighting, Thresholding).
3.  Analyzing the **Bias-Variance Tradeoff**.
4.  Evaluating models using **Recall** vs. **Accuracy**.
