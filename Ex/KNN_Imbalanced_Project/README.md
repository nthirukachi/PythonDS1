# KNN Imbalanced Classification Project

## 📌 Project Overview
This project demonstrates **Imbalanced Classification** for rare disease detection using **k-Nearest Neighbors (k-NN)** with advanced preprocessing: **PCA** (Dimensionality Reduction) and **SMOTE** (Oversampling).

## 📂 Folder Structure
- **notebook/**: Fully explained Jupyter Notebook.
- **documentation/**: Markdown files (Problem, Concepts, Observations).
- **src/**: Original Python script.
- **outputs/**: Expected execution output.

## 🚀 Key Learning Objectives
1.  **Curse of Dimensionality** and why PCA helps k-NN.
2.  **SMOTE** for handling class imbalance.
3.  **Data Leakage** prevention (split *before* SMOTE).
4.  Evaluating with **Recall** and **F1-Score** instead of Accuracy.
